# Stack and Queue Preview Animation

Create a short, silent, looping split-screen MP4 for Module 1. The left side shows plates in a stack and identifies the newest top plate as the next item removed under LIFO. Use a minimal flat educational style, large readable labels, and simple motion: add items, pause to establish order, then remove the highlighted next item.
